# Nexora Swiss

**Your AI companion for life and work in Switzerland.**

Nexora Swiss is a multilingual AI-powered platform designed to help newcomers navigate work, documents, language, taxes, and everyday life in Switzerland.

## V1 languages

- Deutsch
- English
- ትግርኛ (Tigrinya)

## Initial modules

- Career: CV, applications, job assistance, interview preparation
- Documents: upload, understand, translate, reply
- Language: German learning and practical communication
- Tax: canton-aware guided Steuererklärung preparation
- Swiss Life: practical guidance for common Swiss processes

## Technical direction

- Frontend: Next.js + TypeScript
- Backend: FastAPI + Python
- Database: PostgreSQL
- Containers: Docker / Docker Compose
- AI: provider-independent model router with controlled specialized agents

## Product principles

1. Simple and mobile-first.
2. German, English and Tigrinya from day one.
3. Privacy-first handling of personal documents.
4. Human confirmation for high-stakes workflows.
5. Low AI operating cost through model routing.
6. Architecture ready for more languages and communities later.
