# Product Definition

## Mission

Nexora Swiss helps newcomers handle work, language, documents, taxes and everyday Swiss processes through a simple multilingual assistant.

## V1 audience

The first community is Eritrean people living in Switzerland. The architecture remains community-agnostic so more languages can be added later.

## V1 languages

- German (`de`)
- English (`en`)
- Tigrinya (`ti`)

## Core modules

### Career
- user profile
- Swiss CV builder
- tailored applications
- job assistance
- interview practice
- application tracking

### Documents
- PDF/image upload
- document classification
- structured extraction
- simple explanation
- translation
- required-action/deadline extraction
- reply drafting

### Language
- German for work and daily life
- interview practice
- contextual vocabulary
- Tigrinya/English explanations
- voice support later

### Tax
A guided preparation workflow rather than uncontrolled autonomous filing.

- canton and tax-year selection
- personalized document checklist
- Lohnausweis extraction
- bank/insurance document extraction
- missing-document detection
- structured preparation
- user confirmation
- professional review hand-off later

Tax rules must come from verified official canton sources and be versioned by tax year.

### Swiss Life
Later: housing, insurance, employment administration, school/family and common official processes.

## Agent concept

Specialized assistants sit behind one simple user experience:

- Router
- Career Agent
- CV Agent
- Application Agent
- Interview Agent
- Document Agent
- Translation Agent
- German Coach
- Tax Preparation Agent

Agents use explicit tools and bounded workflows. Sensitive/high-stakes actions require confirmation and, where appropriate, professional review.

## Business model hypotheses

- useful free tier
- Plus subscription
- pay-per-service workflows
- professional review marketplace
- organization licenses
- employer services later

Pricing will be validated with real users rather than fixed during initial development.
